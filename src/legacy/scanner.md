# Scanner Recursivo Industrial

[WHAT] Este componente implementa a infraestrutura de varredura profunda necessária para auditorias de conformidade Elite dentro do ecossistema Aesthetic Core.

[WHY] Para garantir que nenhuma área do código (incluindo subdiretórios e módulos aninhados) escape à governança industrial e à geração de manifestos semânticos.

[WHERE] Localizado em `src/scanner.rs`, servindo como o motor de descoberta primário para o binário nativo e o plugin WASM.
