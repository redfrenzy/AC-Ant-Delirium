# Governance Logging and Messaging

/// [WHAT] Centralized messaging and logging macros for the audit engine.
/// [WHY] To provide consistent, context-aware diagnostic output.
/// [WHERE] Diagnostic and messaging layer of the rule engine.

This module contains the `delirium_log!` macro and the standardized violation messages.
It follows the Elite Tracing standard to ensure all audit logs are pedagogical and actionable.
